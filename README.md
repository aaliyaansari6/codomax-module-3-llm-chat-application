# 🤖 AI Chat Application

A simple AI-powered chat application developed as part of the Codomax Internship – Module 3: LLM APIs & Application Development.

## 📌 Project Overview

This project demonstrates how to connect a Large Language Model (LLM) API with a Python application and build an interactive AI chat interface.

The application uses Google's Gemini API and Streamlit to provide real-time AI responses.

## ✨ Features

- 💬 Interactive AI chat
- 🧠 Conversation history
- ⚙️ Custom AI instructions
- 🗑️ Clear chat functionality
- 🔐 Secure API key management using Streamlit Secrets
- ⚠️ Basic API error handling
- 🌐 Live web application using Streamlit
- 🐍 Python-based implementation

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK
- GitHub
- Streamlit Community Cloud

## 🔐 API Key Security

The Gemini API key is stored securely using Streamlit Secrets.

The API key is NOT included in the source code or GitHub repository.
